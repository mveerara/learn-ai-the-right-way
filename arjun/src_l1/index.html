Lesson 1 FAQ

Answers to the questions learners ask most about this lesson.

Do I need maths or coding for this?

Not for this lesson. Course 1 needs only a Google account and a browser. Maths and Python come in later courses, one small step at a time.

Is ChatGPT (or Claude) AI, machine learning or deep learning?

All three at once. These chatbots run on large language models, which are deep learning models. Deep learning is a kind of machine learning, and machine learning is a kind of AI. Remember the three circles.

Does every AI system learn from data?

No. A system built from hand-written rules, like an old spam filter or a tax calculator, is still AI but not machine learning. That's quiz question 5.

What's the difference between AI and data science?

Data science is about getting answers from data, using statistics, charts and often machine learning. It overlaps with AI rather than sitting inside it. This channel teaches the parts of both that you need to build working models.

What exactly are features and labels?

Features are the measurable facts about each example, such as age, ticket class or fare: the columns you learn from. The label is the answer you want to predict, such as survived yes or no.

Supervised or unsupervised: how do I tell them apart?

Ask whether the examples come with the right answers. With answers (labels), it's supervised learning, as in the Titanic example. Without answers, finding groups on its own, it's unsupervised, as in the classroom clustering game.

Why is it called "deep" learning?

Because the neural network has many layers stacked one after another. Each layer builds on the one before: edges, then shapes, then whole objects.

If deep learning is so powerful, why not use it every time?

It needs far more data and computing power, and its decisions are harder to explain. For rows-and-columns data, a simple model is often just as good or better. Start simple, and add complexity only when it earns its place.

Was the Titanic table in the video real data?

The rows were illustrative, laid out like the famous Titanic passenger dataset. You'll work with the real dataset in a lab later in the series.
